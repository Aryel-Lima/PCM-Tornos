Importação inicial do PCM — Tornos Mecânicos

Use esta página uma única vez para transferir o backup JSON do sistema antigo para o banco PostgreSQL central.

Antes de importar: abra a versão antiga do PCM no navegador onde estão os dados, entre em Configurações → Exportar backup (JSON) e salve o arquivo. A importação inicial só funciona se o banco remoto ainda não tiver sido inicializado.
